# Data Dictionary

All data is FICTIONAL, generated by `scripts/generate-data.js` (seeded, so output is repeatable).
Scenario time is fixed in `src/data/meta.json` (`scenarioNow`).

## alerts.json
| Field | Type | Meaning |
|---|---|---|
| id | string | Unique report id, e.g. AL-001 |
| incidentKey | string | Same real-world incident = same key (used for de-duplication) |
| hazard | string | Flood, Storm, Earthquake, Fire, Heat, Water, Power, Road, Health, Landslide, Gas |
| severity | string | info, advisory, warning, critical |
| title | string | Short headline |
| message | string | What is happening and where |
| action | string | The one thing the person should do |
| zone | string | Zone id A-F |
| source | string | Who reported it |
| verified | boolean | true = official source, false = unverified report |
| issuedAt | ISO date | When the report was issued |
| expiresAt | ISO date | When the alert stops being relevant |

## shelters.json
| Field | Type | Meaning |
|---|---|---|
| id | string | e.g. SH-001 |
| name | string | Fictional shelter name |
| zone | string | Zone id A-F |
| address | string | Fictional address |
| capacity | number | Maximum people |
| occupancy | number | People currently inside |
| accessible | boolean | Step-free access |
| hasMedical | boolean | First-aid or medical help on site |
| petsAllowed | boolean | Pets accepted |
| isOpen | boolean | Open right now |
| phone | string | Fictional phone number |
| x, y | number | Position on a 0-100 grid (for the map graphic) |

## supplies.json
| Field | Type | Meaning |
|---|---|---|
| id | string | e.g. SU-001 |
| name | string | Item |
| category | string | Water & Food, Health, Tools, Documents, Comfort |
| quantity | number | Suggested amount per household |
| unit | string | Unit of the quantity |
| essential | boolean | Must-have item |

## checklist.json
| Field | Type | Meaning |
|---|---|---|
| id | string | e.g. CK-001 |
| text | string | The task |
| phase | string | Before, During, After |
| priority | string | high, medium, low |
